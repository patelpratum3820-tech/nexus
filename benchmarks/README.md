# NEXUS Automated Local AI Benchmark Suite

This directory contains benchmark data, comparison analysis, and execution scripts evaluated on the target ASUS VivoBook 15 (Intel Core i3-1215U, 16 GB RAM).

## Contents
- **`model_comparison.md`:** Detailed head-to-head comparison of all 5 pre-installed local models.
- **`hardware_performance.md`:** System telemetry, CPU utilization, and thermal behavior analysis.
- **`benchmark_methodology.md`:** Methodology, sampling intervals, and measurement formulas.
- **`NEXUS_Benchmark/`:** Source scripts (`benchmark.py`, `concurrent_benchmark.py`).
